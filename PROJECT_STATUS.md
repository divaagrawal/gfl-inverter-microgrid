# Project Status and Data Boundary

## Verified findings

- The U.S. Department of Energy explains that grid-forming inverters can provide black start capability, while grid-following inverters synchronise to an existing waveform. See the linked DOE source in `README.md`.

## Illustrative model results

Every value in `results/tables/` is generated by `src/simulator.py` using synthetic controller gains, event timing, load, solar generation, inverter rating, and current limit. They are reproducible but not measured, utility-sourced, or validated.

## Uncertainties and exclusions

- The reduced-order simulation does not model electromagnetic transients, feeder impedances, relay settings, harmonics, protection, hardware limits beyond a single notional current cap, or reconnection synchronisation.
- It does not establish IEEE 1547, utility, or grid-code compliance.
- A future validation phase would require a specified network, controller implementation, HIL/PHIL testing, and measured event data.
